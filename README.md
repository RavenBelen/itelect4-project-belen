# Betta Manager — Frontend

Betta Manager is a web application for managing betta fish, aquarium tanks, and aquatic plants.

## Live Application

[Open Betta Manager](https://itelect4-project-belen.vercel.app)

## Backend API (SAME AS WHAT INSIDE THE BACKEND REPO)

[Backend API](https://itelect4-backend-belen.vercel.app)  
[API health check](https://itelect4-backend-belen.vercel.app/api/health)


## Features

- Sign in and protected pages
- Dashboard overview
- Betta fish management
- Aquarium tank management
- Aquatic plant management
- Reports

## Built With

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Zustand
- TanStack Query
